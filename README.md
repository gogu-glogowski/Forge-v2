Minimalny fundament narzędzia do oceny gotowości Fedory Workstation jako hosta
izolowanych maszyn KVM/QEMU/libvirt.

Projekt rozwija ideę "Little QubesOS" jako narzędzie dla izolowanych maszyn
wirtualnych na hoście Fedora.

Na tym etapie jedynym poleceniem jest:

```text
forge doctor
```

Projekt nie tworzy ani nie modyfikuje maszyn wirtualnych i nie wykonuje operacji
uprzywilejowanych.
